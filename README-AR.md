# ليلة المافيا — نسخ Windows و Android

## ما في الملف؟
- `mafia-online/`: خادم اللعبة وواجهة الويب الأصليان (Render).
- `windows/`: مشروع Electron لإنشاء نسخة EXE للويندوز.
- `android/`: مشروع Android WebView لإنشاء APK تجريبي.
- `.github/workflows/build-downloads.yml`: بناء نسختي Windows وAndroid تلقائيًا على GitHub Actions.

**هذه ملفات مشاريع البناء، وليست ملفات EXE أو APK مبنية مسبقًا.**
تحتاج حساب GitHub لتشغيل البناء السحابي؛ لا تحتاج تثبيت أدوات التطوير على جهازك.

## البناء على GitHub
1. فك الضغط وارفع **محتويات** هذا الملف إلى جذر مستودع `mafia-online`، مع الحفاظ على المجلدات.
2. افتح مستودع GitHub ثم Actions ثم `Build Mafia Online downloads` ثم `Run workflow`.
3. انتظر انتهاء الوظيفتين بعلامة خضراء.
4. افتح التشغيل المكتمل وانزل إلى Artifacts وحمّل:
   - `Mafia-Online-Windows-EXE` (ملف ZIP يحتوي EXE)
   - `Mafia-Online-Android-APK` (ملف ZIP يحتوي APK تجريبي)
5. فك ضغط كل ملف قبل رفعه على itch.io كتحميل قابل للتنزيل.

## ملاحظات
- يحتاج اللاعبون الإنترنت، والتطبيقان يفتحان نفس رابط Render: https://mafia-online-kfu6.onrender.com/
- **تأكد أولًا أن الرابط يعرض اللعبة بدل رسالة «الملف غير موجود».**
- APK الناتج **debug** للاختبار والتوزيع المحدود، وليس إصدارًا نهائيًا موقّعًا للنشر في Google Play.
- قد يُظهر Windows SmartScreen تحذيرًا لأن ملف EXE غير موقّع بشهادة ناشر.
- استضافة Render المجانية قد تتوقف عند الخمول أو إعادة التشغيل؛ غرف اللعبة محفوظة بالذاكرة فقط.
- قبل النشر العام راجع سياسة الخصوصية وآليات الإبلاغ والإشراف على الشات.
- بعد تأكيد بريد itch.io، اختر Downloadable ثم No payments وارفع الملفات المبنية.
- إذا كان مستودعك يحتوي `index.html` و`app.js` و`style.css` في الجذر، انقلها إلى `mafia-online/public/` عند نشر الخادم أو إلى `public/` إذا كان خادم Render يستخدم جذر المستودع. لا تخلط بين جذر المشروع ومجلد `mafia-online` الإضافي.
