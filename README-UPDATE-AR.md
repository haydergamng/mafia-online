# ليلة المافيا — التحديث الكامل v1.4

المنشئ: حيدر المرهون  
المساعد: عبدالله احجيرات  
تاريخ الإصدار: 29 أكتوبر 2026

## ماذا يحتوي التحديث؟

- **الإصدار v1.4** يظهر في الصفحة الرئيسية وداخل الغرفة؛ رقم الإصدار في `package.json` أصبح `1.4.0`.
- **غرف عامة وخاصة** مع رمز الغرفة ورابط الدعوة، وإمكانية تغيير الخصوصية قبل بداية الجولة.
- **إعدادات الغرفة قبل بداية الجولة فقط**؛ تختفي عند بدء اللعبة وتعود عند الرجوع إلى اللوبي.
- **الشات الكتابي والصوتي** يمكن للمضيف تشغيلهما أو إيقافهما من إعدادات الغرفة قبل بدء اللعب. يمكنه تغيير حالة الشات أثناء اللعب من جهة الخادم، لكن الواجهة تخفي لوحة الإعدادات بمجرد بدء الجولة حسب الطلب.
- **الشات الصوتي:** يتكلم الأحياء نهارًا؛ ليلًا يتكلم المافيا فقط، والمستبعد يستمع نهارًا وليلاً إلى قناة المافيا دون الكلام. يلزم HTTPS وإذن الميكروفون، وTURN اختياري لتحسين الاتصال عبر الشبكات.
- **كشف دور المستبعد** خيار قبل البدء؛ يشمل التصويت أو استهداف الليل.
- **المحقق:** يحقق مع لاعب واحد فقط في الليلة؛ يرى هل هدفه من المافيا أم لا، وليس كل أدوار اللاعبين.
- **هدف المافيا موحّد:** أول عضو مافيا حي يحدد هدف الليل، وبقية الأعضاء الأحياء يؤكدون الشخص نفسه؛ اختيار ضحايا مختلفين مرفوض.
- **الانتقال التلقائي إلى النهار** فور اكتمال اختيارات كل أعضاء المافيا الأحياء والطبيب والمحقق؛ دون انتظار المؤقت. القنّاص اختياري ولا يؤخر النهار، وعليه استخدام اختياره قبل اكتمال القرارات الأخرى.
- **حقوق اللعبة**: «المنشئ: حيدر المرهون — المساعد: عبدالله احجيرات» في الواجهة.

## محتويات ZIP

```
server.js             ← منطق الغرف واللعب وإشارات الصوت
engine.js             ← توزيع الأدوار وحسم التصويت والفوز
package.json          ← التشغيل ورقم الإصدار
public/index.html     ← الصفحة الرئيسية وحقوق اللعبة
public/app.js         ← واجهة اللعبة والقوائم والإعدادات
public/style.css      ← تصميم الواجهة
public/voice.js       ← اتصال الصوت WebRTC
 tests/*.test.js      ← اختبارات اللعبة
README-UPDATE-AR.md   ← هذا الملف
```

## تركيب التحديث من الجوال

1. نزّل ZIP وافتح تطبيق الملفات وفكّ الضغط.
2. افتح مستودعك في متصفح Chrome بوضع **موقع سطح المكتب**.
3. ادخل مجلد `public` وارفع `index.html` و`app.js` و`style.css` و`voice.js` مكان الملفات المطابقة.
4. ارجع للمجلد الرئيسي وارفع `server.js` و`engine.js` و`package.json` (بالأسماء نفسها). لا ترفع ملف ZIP نفسه.
5. لو أردت حفظ الاختبارات، ارفع الملفات الثلاثة داخل مجلد `tests`.
6. اعمل **Commit changes** وتحقق من نجاح نشر Render. لا تحذف مجلد `public` أو ملفات مشروعك الأخرى.
7. افتح اللعبة في نافذة خاصة أو حدّث الصفحة تحديثًا كاملاً ثم تأكد من ظهور `v1.4`.

**مهم:** هذا تحديث كود الويب/الخادم، وليس APK أو EXE جاهزًا. ملفات اللعبة محفوظة ضمن ZIP، لكن إعدادات نشر GitHub أو ملفات إنشاء تطبيقات Android/Windows الموجودة في مستودعك تُترك كما هي، وليست مضمنة في هذه الحزمة. لا أستطيع تأكيد تطابق نسخة مستودع GitHub الحالية مع ملفات هذه الحزمة.

## ملاحظة بخصوص الصوت

الصوت يعتمد WebRTC وقد لا يعمل بين بعض شبكات الجوال بدون خادم TURN. يمكن توفير إعدادات `TURN_URLS` و`TURN_USERNAME` و`TURN_CREDENTIAL` في Render عند توفر خادم TURN. لا تضف كلمات مرور TURN في ملفات الواجهة.

## اختبار

على Node.js 20 أو أحدث: `npm test`، ثم اختبار لعب فعلي من أكثر من جهاز، خاصة الصوت.
