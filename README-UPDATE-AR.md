# تحديث ليلة المافيا v1.3

هذا تحديث كامل لملفات خادم اللعبة والواجهة (ليس نسخة APK/EXE جاهزة).

## التثبيت
1. فك ضغط الملف.
2. انسخ محتويات المجلد إلى جذر مستودع mafia-online في GitHub Desktop، مع استبدال الملفات المطابقة.
3. تأكد من نسخ `public/voice.js` الجديد.
4. نفذ Commit ثم Push origin.
5. انتظر نشر Render.

## الميزات
- إعدادات غرفة يتحكم فيها المضيف: الخصوصية، الأدوار، كشف دور المستبعد، الشات النصي والصوتي.
- صوت WebRTC اختياري: النهار للجميع، الليل للمافيا، المستبعد يستمع فقط بما في ذلك ليلًا.
- إعدادات الأدوار وكشف الهوية لا تتغير بعد بدء الجولة.

## تنبيه الصوت
- يحتاج HTTPS والسماح بالمايك.
- الاتصال الحالي يستخدم STUN فقط ولا يحتوي خادم TURN؛ قد لا ينجح بين بعض الشبكات أو خلف جدران الحماية.
- اختبره بين جهازين حقيقيين قبل النشر الواسع.
- صوت اللاعبين المباشرين عبر WebRTC ولا يمر كصوت مسجل عبر الخادم.
