ليلة المافيا — تحديث 1.1

المميزات:
- دور القنّاص: بطاقة واحدة فقط لكل لعبة، يمكن الاحتفاظ بها خلال الليالي؛ عند إطلاقها تُستهلك فورًا.
- إذا الطبيب حمى الهدف ينجو، ولكن الطلقة تُستهلك.
- اسم التطبيق العربي «ليلة المافيا» وأيقونة للجوال والكمبيوتر.
- تعديل رقم النسخة إلى 1.1.0.

التركيب في GitHub Desktop:
1. افتح Repository > Show in Explorer في مشروع mafia-online.
2. فك ضغط هذا الملف ثم انسخ *المحتويات* إلى جذر المشروع (الذي فيه server.js).
3. وافق على استبدال الملفات الموجودة التي تحمل نفس الأسماء، خصوصًا server.js وengine.js وpackage.json، والمجلدات android وwindows وpublic وtests و.github.
   هذه النسخة تحتوي package.json الصحيح لتشغيل السيرفر (npm start يشغّل node server.js)، وملف Windows المنفصل داخل windows/package.json.
4. في GitHub Desktop راجع Changes ثم Commit to main ثم Push origin.
5. سيعيد Render نشر السيرفر تلقائيًا لو Auto-Deploy مفعّل؛ وإلا اختر Deploy latest commit.
6. في GitHub > Actions > Build Mafia Online downloads شغّل Run workflow بعد نشر السيرفر.
7. حمل EXE وAPK الجديدين من Artifacts، اختبرهما، ثم أنشئ Release v1.1.0 وارفع الملفات هناك.

مهم:
- لا تنسخ المجلد المحيط نفسه داخل مشروعك حتى لا يتكرر مستوى المسار؛ انسخ محتوياته.
- الاختبارات الآلية: npm test (5 اختبارات ناجحة محليًا).
- لم أبنِ EXE/APK بنفسي؛ بناءهما يتم في GitHub Actions.
- هذا تطبيق يستعمل سيرفر Render، وبالتالي يلزم اتصال الإنترنت.
- بعض مستخدمي أندرويد قد يحتاجون إزالة إصدار APK التجريبي السابق إذا كان توقيعه مختلفًا.
- بسبب وجود شات، اختبر حماية وإبلاغ وحظر اللاعبين قبل نشر اللعبة للعامة.
