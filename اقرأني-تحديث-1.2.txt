ليلة المافيا — تحديث v1.2: الغرف العامة والخاصة
==============================================

الجديد:
- يستطيع اللاعب إنشاء غرفة عامة تظهر في قائمة الغرف لجميع الزوار.
- أو إنشاء غرفة خاصة لا تظهر في القائمة، ويدخلها الأصدقاء برمز/رابط دعوة.
- قائمة الغرف العامة تعرض الاسم، المضيف، عدد اللاعبين والمقاعد، وزر انضمام.
- تحديث القائمة تلقائيًا كل 10 ثوانٍ وزر تحديث يدوي.
- يستطيع المضيف تغيير الغرفة من عامة إلى خاصة أو بالعكس قبل بدء الجولة.
- الغرفة العامة تختفي من القائمة عند بدء اللعبة.
- الأدوار السابقة، بما فيها القنّاص صاحب الطلقة الواحدة، محفوظة.

طريقة التركيب باستخدام GitHub Desktop:
1- فك ضغط الملف mafia-online-update-v1.2-public-rooms.zip.
2- افتح GitHub Desktop ثم Repository > Show in Explorer.
3- انسخ الملفات والمجلدات الموجودة *داخل* مجلد التحديث إلى جذر مشروع mafia-online.
4- وافق على استبدال الملفات المتطابقة (server.js, package.json، وملفات public، والاختبارات).
5- ارجع لـ GitHub Desktop ثم Commit to main و Push origin.
6- Render ينشر التحديث تلقائيًا إذا كان Auto Deploy مفعّلًا.
   وإلا اختر Manual Deploy > Deploy latest commit.
7- افتح نفس رابط اللعبة https://mafia-online-kfu6.onrender.com/ وتحقق من ظهور v1.2.
8- جرّب إنشاء غرفتين من جهازين أو متصفحين مختلفين.

ملاحظات مهمة:
- هذا تحديث للسيرفر والواجهة فقط. لا يحتاج إعادة بناء EXE أو APK،
  لأن نسختي ويندوز وأندرويد الحاليّتين تعرضان موقع اللعبة من السيرفر.
- الغرف موجودة في ذاكرة السيرفر، وقد تختفي عند إعادة تشغيل Render.
- قائمة الغرف العامة تُظهر الغرف التي لم تبدأ اللعب فقط.
- الغرف الخاصة مخفية من قائمة الاستعراض لكنها ليست محمية بكلمة مرور؛
  كل من لديه رمز الغرفة أو رابط الدعوة يستطيع طلب الدخول.
- قائمة الغرف العامة تظهر في نفس واجهة اللعبة على الجوال والكمبيوتر.
- المحادثات العامة قد تحتوي رسائل من أشخاص لا تعرفهم؛ لا تشارك معلوماتك الشخصية.

اختبار محلي اختياري: npm test (7 اختبارات آلية ناجحة عند الإعداد).
